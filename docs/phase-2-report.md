# Фаза 2: авторизация и семейное пространство

Статус на 1 ноября 2026: **функциональная часть проверена частично; Gate 2 полностью не закрыт**. Семья создана, второй пользователь вошёл по приглашению и состоит в семье. Supabase и Telegram подключены. Пользователь разрешил отложить staging и начать фазу 3; оставшиеся проверки реального входа сохраняются открытыми.

## Подготовлено

- Вход и регистрация по email, восстановление пароля, Telegram OIDC, серверные сессии и создание семьи с первым администратором.
- Миграция профилей, семей, участников и приглашений с RLS, ограниченными правами и серверными операциями. Доступно управление ролями, выход и удаление участников с защитой последнего администратора, а также детские профили без учётной записи.
- Приглашение через ссылку на бота и QR-код: ограниченный срок, отзыв, одноразовый переход и явное подтверждение вступления. Webhook принимает сообщения только с проверенным секретом и из личного чата.
- Перед вступлением отдельно проверяется подписанный Telegram OIDC-токен и его связь с аккаунтом Supabase. Это позволяет сверить Telegram ID, даже если провайдер Supabase не передал его в профиль.
- Без настроенного Supabase доступен гостевой каркас без семейных данных; действия авторизации отключены. Стили новых экранов используют SCSS Modules и существующие компоненты shadcn/ui.

## Проверки и ограничения

- Миграция и политики проверяются в тестах на встроенном PostgreSQL PGlite с минимальной имитацией схемы Supabase Auth. Проверяются изоляция семей, права, приглашения, роли и защита последнего администратора. Это не заменяет проверку на настоящем Supabase.
- Тесты также проверяют подпись и параметры Telegram OIDC-токена, защиту webhook и отдельное подтверждение Telegram ID.
- На подключённой Supabase выполнен `npm run test:db:linked`: временные записи внутри транзакции проверили истечение, отзыв, повторное принятие, чужой Telegram, права ребёнка, защиту последнего администратора, смену роли и исключение. Транзакция откатывается, сообщения бота не отправляются.
- Реальное вступление Дарины подтверждено членством в базе. В браузере с локальной Supabase проверены регистрация, создание семьи, вход, выход, доставка письма в Mailpit, восстановление и смена пароля с последующим входом; тестовые учётная запись и семья удалены. Доставка писем через рабочий почтовый сервис и браузерные сценарии истечения, отзыва, QR и повторного приёма требуют отдельной приёмки.
- Повтор одного webhook update теперь формирует ту же ссылку; повторная доставка сообщения возможна. Новый update создаёт новую ссылку.
- Прошли 47 unit-тестов и 12 гостевых браузерных тестов с отдельной сборкой без Supabase. В Windows запуск с ограниченным доступом к управлению процессами зависал при завершении; запуск с доступом к процессам Chrome корректно завершился. Эти тесты не заменяют E2E с настоящими аккаунтами.
- Docker Desktop и локальный Supabase запущены, все миграции применены. SQL-проверка прошла и на локальной базе с полным откатом тестовых данных. Отдельного Family staging среди доступных проектов нет.
- Локальная SQL-проверка дополнена второй семьёй: один администратор не видит семью и участников другой, а чужой профиль недоступен; после исключения участник теряет доступ к семье. Это начальная проверка фазы 3, она не доказывает изоляцию ещё не созданных личных записей.
- `npm run test:db:local` выполняет SQL-проверку только в контейнере `supabase_db_family-space`. Для проверки локального email использованы `scripts/verify-local-auth.mjs` и `scripts/verify-local-auth-browser.mjs`; реальные почтовые сервисы и рабочие аккаунты не задействованы.
- Локальный сервис vector перезапускается: CLI сообщает, что аналитика на Windows требует отдельной настройки Docker. Доступность базы и SQL-проверку это не нарушило; порт Docker наружу не открывался.
- Уведомления и напоминания о днях рождения относятся к последующим фазам и пока не отправляются.

Функциональная версия опубликована на Vercel; последние локальные изменения требуют сохранения в Git и отдельной публикации. До выполнения оставшихся проверок и требований окружения Gate 2 не отмечается завершённым.
