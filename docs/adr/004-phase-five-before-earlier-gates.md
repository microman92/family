# ADR: начать фазу 5 до закрытия предыдущих Gate

Дата: 03.11.2026. Статус: согласовано пользователем.

## Решение

Начать финансовое ядро до формального закрытия фаз 2–4. Их невыполненные проверки остаются открытыми. Денежные таблицы и операции разрабатываются с проверками семейного и личного доступа, баланса проводок, атомарности и повторных запросов. Фиксация оплаченной покупки не включается до проверки связанных инвариантов в базе.

Миграции сначала проверяются в локальной Supabase. Переход не означает прохождения Gate 3–5 и не отменяет отложенную проверку staging.
