# ADR: начать фазу 4 до полного закрытия Gate 3

Дата: 03.11.2026. Статус: принято пользователем.

## Контекст и решение

Пользователь согласовал начало покупок до формального завершения фазы 3. Новые семейные и личные таблицы создаются только вместе с RLS, проверкой связей и SQL-тестами на изоляцию. Gate 3 и Gate 4 остаются открытыми до выполнения всех обязательных проверок; переход к фазе 5 не подразумевается.

Миграции и тестовые данные проверяются локально до применения к рабочей базе. Отдельный staging остаётся отложенным по предыдущему решению пользователя.
