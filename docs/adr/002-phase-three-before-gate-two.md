# ADR: начать фазу 3 до полного закрытия Gate 2

Дата: 01.11.2026. Статус: принято пользователем для текущего проекта.

## Контекст

Семья создана и второй участник вступил по приглашению. Локальные и облачные SQL-проверки, а также браузерная проверка входа и восстановления пароля с локальной почтой выполнены. Отдельный облачный staging пока не создан: доступны два активных проекта Supabase, а пользователь решил отложить staging и продолжить фазу 3.

Gate 2 остаётся незакрытым: доставку почты через рабочий провайдер и отдельные браузерные сценарии приглашений ещё нужно проверить. Отсутствие staging не объявляется выполненным требованием.

## Решение

Начать подготовку и проверку безопасности фазы 3, сохраняя незавершённые задачи фазы 2 открытыми в `TASKS.md`. Не объявлять Gate 3 пройденным до проверки всех существующих защищённых данных и RLS, а также применения ограничений к соответствующим будущим продуктовым таблицам.

Проверки на локальной базе используют временные записи с откатом. Миграции для рабочей базы сначала проверяются локально; проверки рабочей базы не должны оставлять тестовых записей.

## Последствия

Разработка безопасности может идти параллельно с оставшейся приёмкой входа. До создания будущих личных и финансовых таблиц их изоляция не считается доказанной. Отдельный staging и рабочая доставка email остаются задачами проекта.
